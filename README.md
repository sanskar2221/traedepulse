# TradePulse - Crypto Portfolio Tracker

## 🚀 Tech Stack
- React
- Tailwind CSS
- Node.js
- Express
- MongoDB
- JWT Authentication

## ✨ Features
- User Registration & Login
- Protected Routes
- Dashboard with Charts
- Trade History
- Profile Settings
- Change Password
- Logout

## ⚙️ Setup Instructions

### Backend
cd server
npm install
npm run dev

### Frontend
cd client
npm install
npm run dev
